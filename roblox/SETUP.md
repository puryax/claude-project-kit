# Roblox プロジェクトの環境構築（Rojo + Studio MCP）

> **誰が読むか: 人間と Claude の両方。** 環境構築は人間が手を動かす部分があるので、両方が読む。

**「深層」で実際に使った構成。2026-09 時点。**

---

## 全体の形

```
ローカルのファイル  --[Rojo]-->  Roblox Studio   （★ 一方通行 ★）
                    <--[MCP]-->                  （読み書き・Play 操作）
```

★★ **Rojo は一方通行。** ★★ Studio 側でスクリプトを編集しても**ローカルには戻らない**
（次の同期で上書きされて消える）。**スクリプトは必ずローカルで編集する。**

★ **逆に、3Dモデルはローカルには存在しない。** ★ プレイスの中にしかないので、
**Git では守られない。**（「深層」D-17）**人間が定期的にプレイスを保存すること。**

## 手順

### 1. フォルダを作る
```
<プロジェクト名>/
├ default.project.json
├ src/
│  ├ server/    → ServerScriptService へ
│  ├ client/    → StarterPlayerScripts へ
│  └ shared/    → ReplicatedStorage へ
├ docs/
└ CLAUDE.md
```

### 2. `default.project.json`
同期先のフォルダ名は **1つに統一する**（「深層」では `Shinsou`）。
バラバラだと、Studio 側に孤児のフォルダが残って原因不明の不具合になる。

### 3. `rojo serve` を起動する
`serve.bat` を作り、**末尾に `pause` を入れる。**
入れないと、起動に失敗したときウィンドウが一瞬で閉じてエラーが読めない。

★ **ポートが他の rojo に取られていると即座に落ちる。** ★ そこが一番多い失敗。

### 4. Studio の Rojo プラグインで Connect を押す
★★ **rojo サーバーを再起動すると、プラグインは必ず切断される。** ★★
**自動では戻らない。人間が Connect を押すまで復旧しない。**

---

## ★★ 同期が生きているかの確かめ方（毎回やる）★★

**TCP 接続が張られていることは根拠にならない。** 切断後も接続が残って見える。
**「さっきまで動いていた」も根拠にならない。**

確実な手順：
1. `src/shared/_SyncTest.luau` を作る（中身は目印の文字列だけ）
2. Studio 側に現れるか `execute_luau` で確かめる（`.Source` を読む）
3. **必ず削除する**

---

## ★★ Studio MCP の落とし穴（最重要）★★

### `execute_luau` の `require` は、動いているゲームとは別の実体を返す
サービスが抱えている**生のデータには触れない。**
内部状態を覗きたいときは、**`BindableFunction` の受け口をサーバーに立てておく**
（「深層」D-97。`ServerStorage` に置けばクライアントからは見えない）。

### 編集モード（Edit）の `require` は、同期より前の古い実体を返し続ける
**Studio を開いたままモジュールを書き換えても、編集モードでは古い内容が見える。**
同期の成否は `.Source` を読んで判断すること。

### 編集モードのコマンドバーは Plugin 権限で動く
**サーバースクリプトでは書けないプロパティも書けてしまう。**
★ **プロパティ代入が通るかは、必ず Play（Server）で確かめる。** ★（「深層」D-26）

### 最大人数などのゲーム設定はコードから変更できない
Studio の Game Settings で人間が設定する。

## 素材（3Dモデル・音・画像）の置き場所

★★ **`ServerStorage` に置くこと。`ReplicatedStorage` には置かない。** ★★

`ReplicatedStorage` は**参加した瞬間に全部クライアントへ送られる**。
サーバーしか使わない素材をそこに置くと、**参加直後の通信が丸ごと無駄になる。**
「深層」では 7,741 個 → 47 個に減らして、参加直後の操作遅延が解消した（D-239）。

**クライアントも使うもの（Config・Remote・共有モジュール）だけ** `ReplicatedStorage` に置く。
