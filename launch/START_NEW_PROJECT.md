# 新しいプロジェクトを始める（種類を問わず）

> **誰が読むか: Claude Code。** 人間が「このファイルを読んで進めて」と渡す。
> **層: Claude に渡す紙 ②。** 前: `FOR_CHAT.md` で GDD を作る（既にあるなら飛ばす）／ 後: そのプロジェクトの CLAUDE.md と docs/ で回る。
> ★ **GDD（または「何を作るか」）が手元にあってから渡す。** ★ 無い状態で渡すと、Claude が中身を決めにいく。

**このファイルを新規セッションの Claude に読ませる。それだけで立ち上がる。**

---

## 人間がやること（5分）

1. プロジェクトのフォルダを作る
2. そのフォルダで Claude Code の新規セッションを立ち上げる
3. 下の「最初のプロンプト」をそのまま貼る

---

## 最初のプロンプト（コピーして貼る）

★★ **貼る前に、3か所を自分の状況に合わせること。** ★★

| 印 | どうするか |
|---|---|
| `<ClaudeKit を置いた場所>` | 自分の実際のパスに**置き換える**（例: `C:\Users\<自分>\Documents\ClaudeKit`） |
| `<Roblox なら〜>` の行 | **人間向けの注記。**Roblox なら注記だけ消して次の行を残す。違うなら行ごと消す |
| ★ **GDD の有無** ★ | **下の A か B の どちらか1つ**を選ぶ。**両方貼らない** |

```
これから新しいプロジェクトを始めます。
```

## 最初の1週間でやること

1. **`00_GDD.md` を書く**（何を作るのか。ここは Claude のチャット機能でやると速い）
2. **`01_SPEC.md` に数値を全部落とす**（曖昧なところは疑問として `05_DECISIONS.md` へ）
3. **`03_TASKS.md` にタスクと完了条件を並べる**（完了条件は**測れる形**で書く）
4. **環境構築**（Roblox なら `roblox/SETUP.md`）
5. **一番小さいタスクを1つ通してみる**（進め方が回るかの確認）

★ **5 が大事。** ★ いきなり大きいタスクから始めると、
進め方の欠陥に気づくのが遅れて、そのぶん全部やり直しになる。
