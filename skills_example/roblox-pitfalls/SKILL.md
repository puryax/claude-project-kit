# Roblox の落とし穴

★ **詳細は `<ClaudeKit を置いた場所>\roblox\PITFALLS.md` を読むこと。** ★
実測で確かめた 30 件が、症状から引ける形で並んでいる。
環境構築は `ClaudeKit\roblox\SETUP.md`。

## 作業前に必ず思い出すこと

### 1. ★ Studio の状態を語る前に、同期が生きているか検証する ★
TCP 接続も「さっきまで動いていた」も根拠にならない。
一時ファイルを作って Studio に現れるか確かめ、**必ず消す。**

### 2. ★ `execute_luau` の `require` は、動いているゲームとは別の実体 ★
サービスの内部状態は覗けない。**外から観測できる経路で測る。**
編集モードの `require` は同期前の古い実体を返し続けるので、`.Source` を読んで判断する。

### 3. ★ プロパティ代入が通るかは、必ず Play（Server）で確かめる ★
編集モードのコマンドバーは Plugin 権限なので、**本来書けないものも書けてしまう。**

### 4. ★ Studio で再現しない不具合が必ずある ★
Studio は通信・読み込み・ストリーミングが 0 秒。**本番では 0 秒ではない。**
「公開版だけ重い／遅れる」なら、まず次を疑う。
- `ReplicatedStorage` に**クライアントが使わないもの**を置いていないか
- `StreamingEnabled` のまま遠くへテレポートしていないか
- クライアントが**初めて使うアセット**を取りに行っていないか

### 5. ★ 遅れるのは「サーバーとの往復が要る操作」だけかどうかを見る ★
人間の報告が「A は遅いが B は遅くない」なら、この線で分かれていないか真っ先に確かめる。
切り分けが一発で決まる。

### 6. ★ おかしいと思ったら、まず自分の測り方を疑う ★
`PlaybackLoudness` は編集モードでは動かない。`AnimationTrack.Length` は直後は 0。
`IsPlaying` は指示が届いた時点で true。レイは撃つ位置で結果が変わる。
**実装を疑うのはその次。**
