# skills_example — スキルの雛形

> **誰が読むか: 人間。** 自分の環境へコピーして使う。

**Claude Code のスキル**（`/` で名前を呼べる手順書）の雛形。
中の `<ClaudeKit を置いた場所>` を**自分の実際のパスに書き換えてから**、
次の場所へコピーする。

```
Windows: C:\Users\<自分>\.claude\skills\
macOS  : ~/.claude/skills/
```

★ ここへ置くと**どのフォルダで新規セッションを立ち上げても使える。** ★
★ **名前で呼ばなくてもよい。** ★ 説明文を見て Claude が自分で判断して読む。

| スキル | いつ効くか |
|---|---|
| `project-kickoff` | 新しい長期プロジェクトを立ち上げるとき |
| `roblox-pitfalls` | Roblox の作業をするとき |
