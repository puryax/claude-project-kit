# 03_TASKS — タスク一覧

## 進め方
- 上から1つずつ。**着手前に認識合わせのレベル（A/B/C）を人間に聞く。**
- ★ **完了条件は「測れる形」で書く。** ★「ちゃんと動く」は完了条件にならない
- ★ **タスクを終えたその場でチェックを入れる。** ★ 後回しにすると必ず溜まる
